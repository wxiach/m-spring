> 一个用于学习 IoC 与 AOP 原理的迷你 Spring 实现。<br>

IoC 支持组件扫描、按名称或类型获取 Bean、构造器与字段注入、单例与原型作用域、通过三级缓存处理单例字段循环依赖及 Bean 后置处理；AOP 支持切点匹配、五种通知和环绕通知嵌套。
